### 4. TTS播放完成 → IDLE

**行数**: 676-691

```kotlin
private fun setupTTSCompletionCallback() {
    speechOutputDeviceWrapper.runWhenFinishedSpeaking {
        scope.launch {
            delay(1000)
            if (AsrHandler.isStarted()) {
                updateState(uiState = LISTENING, ttsText = "", displayText = "LISTENING")
            } else {
                transitionToState(VoiceAssistantUIState.IDLE, reason = "TTS播放完成")
            }
        }
    }
}
```

**触发条件**: TTS播放完成 && ASR未运行  
**前置状态**: SPEAKING  
**后置状态**: IDLE 或 LISTENING  
**功能变化**: ❌ 停止ASR (如果运行), ✅ 启动Wake

```kotlin
override fun onWakeWordError(error: Throwable) {
    // 第1步：转换到ERROR
    transitionToState(VoiceAssistantUIState.ERROR, reason = "唤醒词错误: ${error.message}")
    
    // 第2步：3秒后恢复IDLE
    scope.launch {
        delay(3000)
        transitionToState(VoiceAssistantUIState.IDLE, reason = "错误恢复")
    }
}
```

**触发条件**: WakeService 遇到错误  
**前置状态**: 任何  
**后置状态**: ERROR → (3秒后) IDLE  
**功能变化**: ❌ 停止ASR, ⏸️ Wake暂停 → (3秒后) ✅ 启动Wake

## 🎯 使用示例

### 手动触发状态转换

```kotlin
// 用户手动停止
voiceAssistantStateProvider.transitionToState(
    VoiceAssistantUIState.IDLE,
    reason = "用户手动停止"
)

// 测试用例
voiceAssistantStateProvider.transitionToState(
    VoiceAssistantUIState.LISTENING,

voiceAssistantStateProvider.transitionToState(
    VoiceAssistantUIState.ERROR,

)
```


## 📊 状态一致性保证

### 自动验证

每次调用 `transitionToState()` 都会：

1. ✅ 检查当前状态，避免重复转换
2. ✅ 根据目标状态自动管理 AsrHandler
3. ✅ 根据目标状态自动管理 WakeService
4. ✅ 更新 UI 状态
5. ✅ 记录详细日志
6. ✅ 发送监控事件

### 状态不变量

| 状态 | 不变量 |
|------|--------|
| IDLE | `!AsrHandler.isStarted() && WakeService.isRunning()` |
| LISTENING | `AsrHandler.isStarted() && !WakeService.isRunning()` |
| SPEAKING | `!WakeService.isRunning()` |
| ERROR | `!AsrHandler.isStarted()` |

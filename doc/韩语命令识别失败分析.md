## 三、问题根源分析

### 3.1 ASR识别错误

**问题：**
- ASR识别结果与用户实际说话内容不一致
- 常见错误：
  - "화면" → "하면"
  - "HDMI" → "얘 나 이들이"
  - "해이" → "행이"

**影响：**
- 技能匹配时，识别文本与技能模板不匹配
- 即使技能评分算法正确，也无法匹配到正确的技能

**解决方案：**
1. **文本规范化处理**：添加常见误识别的映射表
2. **模糊匹配**：改进技能评分算法，支持部分匹配
3. **上下文理解**：利用上下文信息纠正识别错误

### 3.2 文本清理过于激进

**当前清理逻辑（EnhancedFloatingWindowService.kt:126-129）：**
```kotlin
val cleanedText = finalText.trim()
    .replace(Regex("\\s+"), " ")
    .replace(Regex("[.,。，!！?？;；:：]"), "")
    .trim()
```

**问题：**
- 只移除了标点符号和多余空格
- 没有处理ASR识别错误
- 没有处理多余内容

**解决方案：**
1. **添加文本规范化**：处理常见误识别
2. **智能截断**：移除明显多余的内容
3. **保留关键信息**：确保重要词汇不被移除

### 3.3 技能评分阈值过高

**当前阈值（SkillRanker.kt）：**
- HIGH_THRESHOLD_1 = 0.8f
- MEDIUM_THRESHOLD_2 = 0.80f
- HIGH_THRESHOLD_2 = 0.60f
- LOW_THRESHOLD_3 = 0.80f
- MEDIUM_THRESHOLD_3 = 0.60f
- HIGH_THRESHOLD_3 = 0.49f

**问题：**
- 当ASR识别有错误时，评分可能低于阈值
- 即使部分匹配正确，也可能无法通过阈值检查

**解决方案：**
1. **降低阈值**：对于常见命令，适当降低阈值
2. **改进评分算法**：考虑部分匹配和相似度
3. **添加容错机制**：对于高置信度的部分匹配，允许通过

## 四、解决方案

### 4.1 文本规范化处理

在`EnhancedFloatingWindowService`的`setFinalResultCallback`中添加文本规范化：

```kotlin
private fun normalizeKoreanText(text: String): String {
    var normalized = text
    
    // 常见ASR识别错误纠正
    val corrections = mapOf(
        "하면" to "화면",
        "행이" to "해이",
        "얘 나 이들이" to "에이치디엠아이",
        "에이치 디에마이" to "에이치디엠아이",
        "유에스비씨" to "유에스비",
        "오피피에스" to "오피에스",
    )
    
    corrections.forEach { (wrong, correct) ->
        normalized = normalized.replace(wrong, correct, ignoreCase = true)
    }
    
    return normalized
}
```

### 4.2 智能文本清理

改进文本清理逻辑，移除明显多余的内容：

```kotlin
private fun cleanTextForSkillMatching(text: String): String {
    var cleaned = text.trim()
        .replace(Regex("\\s+"), " ")
        .replace(Regex("[.,。，!！?？;；:：]"), "")
        .trim()
    
    // 移除明显多余的内容（如果包含多个完整句子，只保留第一个）
    val sentences = cleaned.split(Regex("[。！？\\.!?]"))
    if (sentences.size > 1) {
        // 检查第一个句子是否包含命令关键词
        val firstSentence = sentences[0].trim()
        val hasCommandKeywords = firstSentence.contains(Regex("연결|실행|켜|꺼|변경|지워"))
        if (hasCommandKeywords) {
            cleaned = firstSentence
        }
    }
    
    return cleaned
}
```

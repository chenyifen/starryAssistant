## 概述

授权系统支持两种激活方式：

1. **MAC地址白名单激活**：通过MAC地址验证，如果MAC地址在白名单中，自动激活
2. **激活码激活**：用户输入激活码，通过激活码API激活，激活时需要传入MAC地址

**推荐流程**：应用启动时优先使用MAC地址验证，如果验证失败，再引导用户使用激活码激活。

## 核心流程

```
应用启动
    ↓
检查本地激活状态
    ↓
已激活？
    ├─ 是 → 正常启动应用
    └─ 否 → 通过MAC地址验证
            ↓
        MAC地址在激活名单？
            ├─ 是 → 保存激活状态 → 正常启动
            └─ 否 → 提示用户输入激活码
                    ↓
                激活码激活（传入MAC地址）
                    ↓
                保存激活状态 → 正常启动
```

## MAC地址验证流程

### 流程说明

1. 应用启动时，首先调用 `verify-by-mac` API，传入应用ID和MAC地址
2. 如果MAC地址在激活名单中（白名单或已激活的授权码），API返回 `valid: true`
3. 应用将激活状态保存到本地存储，标记为已激活
4. 下次启动时，直接读取本地激活状态，无需再次请求服务器

### API接口

**请求地址**：`POST /api/licenses/verify-by-mac`

**请求参数**：
```json
{
  "appId": "YOUR-APP-ID",      // 应用ID（必填）
  "mac": "00:1B:44:11:3A:B7",  // MAC地址（必填）
  "name": "设备名称",           // 设备名称（可选，首次激活时记录）
  "deviceId": "DEVICE-001"     // 设备ID（可选，首次激活时记录）
}
```

**响应结果**：
```json
{
  "success": true,
  "valid": true,              // 是否激活
  "status": "active",         // 状态：active, expired
  "licenseKey": "xxx",        // 授权码（如果找到）
  "activatedAt": "2024-01-01T00:00:00.000Z",
  "expiresAt": "2025-01-01T00:00:00.000Z",
  "fromWhitelist": true,      // 是否来自白名单
  "message": "MAC地址在白名单中，已自动激活"
}
```

```kotlin
import android.content.Context
import android.net.wifi.WifiManager
import android.net.ConnectivityManager
import android.net.NetworkCapabilities
import android.os.Build
import okhttp3.*
import okhttp3.MediaType.Companion.toMediaType
import okhttp3.RequestBody.Companion.toRequestBody
import org.json.JSONObject
import java.io.IOException

/**
 * 通过MAC地址验证授权状态
 */
suspend fun verifyByMac(
    appId: String,
    mac: String,
    name: String? = null,
    deviceId: String? = null,
    apiBaseUrl: String
): Result<JSONObject> {
    return try {
        val json = JSONObject().apply {
            put("appId", appId)
            put("mac", mac)
            name?.let { put("name", it) }
            deviceId?.let { put("deviceId", it) }
        }
        
        val requestBody = json.toString()
            .toRequestBody("application/json".toMediaType())
        
        val request = Request.Builder()
            .url("$apiBaseUrl/api/licenses/verify-by-mac")
            .post(requestBody)
            .build()
        
        val client = OkHttpClient()
        val response = client.newCall(request).execute()
        
        if (response.isSuccessful) {
            val responseBody = response.body?.string()
            Result.success(JSONObject(responseBody ?: "{}"))
        } else {
            Result.failure(IOException("请求失败: ${response.code}"))
        }
    } catch (e: Exception) {
        Result.failure(e)
    }
}

// 使用示例（在协程中）
val result = verifyByMac(
    appId = "YOUR-APP-ID",
    mac = "00:1B:44:11:3A:B7",
    name = "我的设备",
    deviceId = "DEVICE-001",
    apiBaseUrl = "https://your-domain.com"
)

result.onSuccess { data ->
    val valid = data.optBoolean("valid", false)
    if (valid) {
        Log.d("Activation", "设备已激活")
        // 保存激活状态到本地
        saveActivationStatus(context, true, data)
    } else {
        Log.d("Activation", "设备未激活: ${data.optString("message")}")
    }
}.onFailure { error ->
    Log.e("Activation", "MAC地址验证失败", error)
}
```

```java
     */

            JSONObject json = new JSONObject();

            json.put("mac", mac);

                .url(apiBaseUrl + "/api/licenses/verify-by-mac")
                .post(body)
                .build();
            
            OkHttpClient client = new OkHttpClient();
            client.newCall(request).enqueue(callback);
        } catch (Exception e) {
            Log.e("Activation", "MAC地址验证失败", e);
        }
    }
}
```

## 激活码激活流程

### 流程说明

1. 如果MAC地址验证失败，应用提示用户输入激活码
2. 用户输入激活码后，调用 `apply` API，**必须传入MAC地址**
3. 激活成功后，应用将激活状态保存到本地存储
4. 应用复位后，即使激活码丢失，也可以通过MAC地址验证恢复激活状态

### API接口

**请求地址**：`POST /api/licenses/apply`

**请求参数**：
```json
{
  "licenseKey": "YOUR-LICENSE-KEY",  // 激活码（必填）
  "appId": "YOUR-APP-ID",            // 应用ID（必填）
  "userInfo": {
    "name": "用户姓名",                // 可选
    "email": "user@example.com",     // 可选
    "deviceId": "DEVICE-001",        // 可选
    "macAddress": "00:1B:44:11:3A:B7" // MAC地址（必填）
  }
}
```

**响应结果**：
```json
{
  "success": true,
  "message": "授权码激活成功",
  "license": {
    "licenseKey": "xxx",
    "status": "active"
  }
}
```

## 应用启动验证逻辑

### 完整启动流程

应用启动时应按以下顺序进行验证：

1. **读取本地激活状态**
   - 检查本地是否已保存激活状态
   - 如果已激活，直接启动应用（可选：定期后台验证）

2. **MAC地址验证**
   - 获取设备MAC地址
   - 调用 `verify-by-mac` API验证
   - 如果验证成功，保存激活状态并启动应用

3. **激活码激活**
   - 如果MAC地址验证失败，提示用户输入激活码
   - 用户输入后调用 `apply` API激活
   - 激活成功后保存状态并启动应用

### 本地存储激活状态

Android应用应将激活状态保存到SharedPreferences或SQLite数据库，包含以下信息：

```json
{
  "activated": true,                    // 是否已激活
  "mac": "00:1B:44:11:3A:B7",          // MAC地址
  "licenseKey": "xxx",                  // 授权码（如果有）
  "activatedAt": "2024-01-01T00:00:00.000Z",  // 激活时间
  "expiresAt": "2025-01-01T00:00:00.000Z",    // 过期时间（如果有）
  "lastVerifiedAt": "2024-01-01T00:00:00.000Z" // 最后验证时间
}
```

### Android代码示例

#### Kotlin示例 - 使用SharedPreferences

```kotlin
import android.content.Context
import android.content.SharedPreferences
import android.net.wifi.WifiManager
import android.net.ConnectivityManager
import android.net.NetworkCapabilities
import android.os.Build
import android.util.Log
import org.json.JSONObject
import java.net.NetworkInterface
import java.text.SimpleDateFormat
import java.util.*

class ActivationManager(private val context: Context, private val appId: String, private val apiBaseUrl: String) {
    private val prefs: SharedPreferences = context.getSharedPreferences("activation_prefs", Context.MODE_PRIVATE)
    private val STORAGE_KEY = "app_activation_status"
    
    /**
     * 获取MAC地址
     * Android 6.0+ 无法直接获取WiFi MAC地址，需要其他方式
     */
    fun getMacAddress(): String? {
        try {
            // 方法1: 通过NetworkInterface获取（推荐）
            val interfaces = Collections.list(NetworkInterface.getNetworkInterfaces())
            for (networkInterface in interfaces) {
                val macBytes = networkInterface.hardwareAddress ?: continue
                val sb = StringBuilder()
                for (byte in macBytes) {
                    sb.append(String.format("%02X:", byte))
                }
                if (sb.isNotEmpty()) {
                    sb.deleteCharAt(sb.length - 1)
                    val mac = sb.toString()
                    // 排除回环接口和无效MAC
                    if (!mac.equals("02:00:00:00:00:00", ignoreCase = true) && 
                        mac.isNotEmpty()) {
                        return mac
                    }
                }
            }
            
            // 方法2: 通过WifiManager获取（Android 6.0+需要位置权限）
            if (Build.VERSION.SDK_INT < Build.VERSION_CODES.M) {
                val wifiManager = context.applicationContext.getSystemService(Context.WIFI_SERVICE) as WifiManager
                val wifiInfo = wifiManager.connectionInfo
                val mac = wifiInfo.macAddress
                if (mac != null && mac.isNotEmpty() && mac != "02:00:00:00:00:00") {
                    return mac
                }
            }
            
            // 方法3: 使用Android ID作为备选（如果无法获取MAC地址）
            // 注意：这不是真正的MAC地址，但可以作为设备唯一标识
            val androidId = android.provider.Settings.Secure.getString(
                context.contentResolver,
                android.provider.Settings.Secure.ANDROID_ID
            )
            return androidId ?: "UNKNOWN"
        } catch (e: Exception) {
            Log.e("Activation", "获取MAC地址失败", e)
            return null
        }
    }
    
    /**
     * 保存激活状态
     */
    fun saveActivationStatus(activated: Boolean, data: Map<String, String?> = emptyMap()) {
        val mac = data["mac"] ?: getMacAddress() ?: ""
        val status = JSONObject().apply {
            put("activated", activated)
            put("mac", mac)
            put("licenseKey", data["licenseKey"] ?: JSONObject.NULL)
            put("activatedAt", data["activatedAt"] ?: SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US).format(Date()))
            put("expiresAt", data["expiresAt"] ?: JSONObject.NULL)
            put("lastVerifiedAt", SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US).format(Date()))
        }
        
        prefs.edit().putString(STORAGE_KEY, status.toString()).apply()
    }
    
    /**
     * 获取激活状态
     */
    fun getActivationStatus(): JSONObject? {
        val stored = prefs.getString(STORAGE_KEY, null) ?: return null
        return try {
            JSONObject(stored)
        } catch (e: Exception) {
            Log.e("Activation", "读取激活状态失败", e)
            null
        }
    }
    
    /**
     * 检查是否已激活
     */
    fun isActivated(): Boolean {
        val status = getActivationStatus() ?: return false
        if (!status.optBoolean("activated", false)) return false
        
        // 检查是否过期
        val expiresAtStr = status.optString("expiresAt", null)
        if (expiresAtStr != null && expiresAtStr != "null") {
            try {
                val sdf = SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US)
                val expiresAt = sdf.parse(expiresAtStr)
                if (expiresAt != null && Date() > expiresAt) {
                    return false
                }
            } catch (e: Exception) {
                Log.e("Activation", "解析过期时间失败", e)
            }
        }
        
        return true
    }
    
    /**
     * 应用启动时验证
     */
    suspend fun checkOnStartup(): ActivationResult {
        // 1. 检查本地激活状态
        if (isActivated()) {
            Log.d("Activation", "应用已激活（从本地缓存）")
            return ActivationResult(activated = true, fromCache = true)
        }
        
        // 2. 获取MAC地址
        val mac = getMacAddress()
        if (mac.isNullOrEmpty()) {
            return ActivationResult(activated = false, error = "无法获取MAC地址")
        }
        
        // 3. 通过MAC地址验证
        return try {
            val macResult = verifyByMac(appId, mac, null, null, apiBaseUrl)
            macResult.onSuccess { data ->
                val valid = data.optBoolean("valid", false)
                if (valid) {
                    Log.d("Activation", "MAC地址验证成功")
                    saveActivationStatus(true, mapOf(
                        "mac" to mac,
                        "licenseKey" to data.optString("licenseKey", null),
                        "activatedAt" to data.optString("activatedAt", null),
                        "expiresAt" to data.optString("expiresAt", null)
                    ))
                    ActivationResult(activated = true, fromMac = true)
                } else {
                    Log.d("Activation", "MAC地址未在激活名单中: ${data.optString("message")}")
                    ActivationResult(activated = false, needLicense = true, 
                                   message = data.optString("message"))
                }
            }.onFailure { error ->
                Log.e("Activation", "MAC地址验证失败", error)
                ActivationResult(activated = false, error = error.message)
            }.getOrThrow()
        } catch (e: Exception) {
            ActivationResult(activated = false, error = e.message)
        }
    }
    
    /**
     * 使用激活码激活
     */
    suspend fun activate(licenseKey: String, userInfo: Map<String, String>? = null): ActivationResult {
        val mac = getMacAddress()
        if (mac.isNullOrEmpty()) {
            return ActivationResult(success = false, message = "无法获取MAC地址")
        }
        
        return try {
            val result = activateByLicense(licenseKey, appId, mac, userInfo, apiBaseUrl)
            result.onSuccess { data ->
                val success = data.optBoolean("success", false)
                if (success) {
                    Log.d("Activation", "激活码激活成功")
                    val licenseKeyFromResponse = data.optJSONObject("license")?.optString("licenseKey")
                    saveActivationStatus(true, mapOf(
                        "mac" to mac,
                        "licenseKey" to licenseKeyFromResponse,
                        "activatedAt" to SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US).format(Date())
                    ))
                    ActivationResult(success = true)
                } else {
                    ActivationResult(success = false, message = data.optString("message"))
                }
            }.onFailure { error ->
                ActivationResult(success = false, message = error.message)
            }.getOrThrow()
        } catch (e: Exception) {
            ActivationResult(success = false, message = e.message)
        }
    }
}

/**
 * 激活结果数据类
 */
data class ActivationResult(
    val activated: Boolean = false,
    val success: Boolean = false,
    val fromCache: Boolean = false,
    val fromMac: Boolean = false,
    val needLicense: Boolean = false,
    val message: String? = null,
    val error: String? = null
)
```

```java
import android.content.Context;
import android.content.SharedPreferences;
import android.net.wifi.WifiManager;
import android.os.Build;
import android.util.Log;
import org.json.JSONObject;
import java.net.NetworkInterface;
import java.text.SimpleDateFormat;
import java.util.*;

public class ActivationManager {
    private static final String STORAGE_KEY = "app_activation_status";
    private static final String PREFS_NAME = "activation_prefs";
    
    private Context context;
    private String appId;
    private String apiBaseUrl;
    private SharedPreferences prefs;
    
    public ActivationManager(Context context, String appId, String apiBaseUrl) {
        this.context = context;
        this.appId = appId;
        this.apiBaseUrl = apiBaseUrl;
        this.prefs = context.getSharedPreferences(PREFS_NAME, Context.MODE_PRIVATE);
    }
    
    /**
     * 获取MAC地址
     */
    public String getMacAddress() {
        try {
            // 方法1: 通过NetworkInterface获取
            List<NetworkInterface> interfaces = Collections.list(NetworkInterface.getNetworkInterfaces());
            for (NetworkInterface networkInterface : interfaces) {
                byte[] macBytes = networkInterface.getHardwareAddress();
                if (macBytes == null) continue;
                
                StringBuilder sb = new StringBuilder();
                for (byte b : macBytes) {
                    sb.append(String.format("%02X:", b));
                }
                if (sb.length() > 0) {
                    sb.deleteCharAt(sb.length() - 1);
                }
                String mac = sb.toString();
                if (!mac.equals("02:00:00:00:00:00") && !mac.isEmpty()) {
                    return mac;
                }
            }
            
            // 方法2: 通过WifiManager获取（Android 6.0+需要位置权限）
            if (Build.VERSION.SDK_INT < Build.VERSION_CODES.M) {
                WifiManager wifiManager = (WifiManager) context.getApplicationContext()
                    .getSystemService(Context.WIFI_SERVICE);
                if (wifiManager != null) {
                    String mac = wifiManager.getConnectionInfo().getMacAddress();
                    if (mac != null && !mac.isEmpty() && !mac.equals("02:00:00:00:00:00")) {
                        return mac;
                    }
                }
            }
            
            // 方法3: 使用Android ID作为备选
            String androidId = android.provider.Settings.Secure.getString(
                context.getContentResolver(),
                android.provider.Settings.Secure.ANDROID_ID
            );
            return androidId != null ? androidId : "UNKNOWN";
        } catch (Exception e) {
            Log.e("Activation", "获取MAC地址失败", e);
            return null;
        }
    }
    
    /**
     * 保存激活状态
     */
    public void saveActivationStatus(boolean activated, Map<String, String> data) {
        String mac = data != null && data.containsKey("mac") ? 
            data.get("mac") : getMacAddress();
        if (mac == null) mac = "";
        
        try {
            JSONObject status = new JSONObject();
            status.put("activated", activated);
            status.put("mac", mac);
            status.put("licenseKey", data != null && data.containsKey("licenseKey") ? 
                data.get("licenseKey") : JSONObject.NULL);
            status.put("activatedAt", data != null && data.containsKey("activatedAt") ? 
                data.get("activatedAt") : new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US).format(new Date()));
            status.put("expiresAt", data != null && data.containsKey("expiresAt") ? 
                data.get("expiresAt") : JSONObject.NULL);
            status.put("lastVerifiedAt", new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US).format(new Date()));
            
            prefs.edit().putString(STORAGE_KEY, status.toString()).apply();
        } catch (Exception e) {
            Log.e("Activation", "保存激活状态失败", e);
        }
    }
    
    /**
     * 获取激活状态
     */
    public JSONObject getActivationStatus() {
        String stored = prefs.getString(STORAGE_KEY, null);
        if (stored == null) return null;
        
        try {
            return new JSONObject(stored);
        } catch (Exception e) {
            Log.e("Activation", "读取激活状态失败", e);
            return null;
        }
    }
    
    /**
     * 检查是否已激活
     */
    public boolean isActivated() {
        JSONObject status = getActivationStatus();
        if (status == null) return false;
        if (!status.optBoolean("activated", false)) return false;
        
        // 检查是否过期
        String expiresAtStr = status.optString("expiresAt", null);
        if (expiresAtStr != null && !expiresAtStr.equals("null")) {
            try {
                SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US);
                Date expiresAt = sdf.parse(expiresAtStr);
                if (expiresAt != null && new Date().after(expiresAt)) {
                    return false;
                }
            } catch (Exception e) {
                Log.e("Activation", "解析过期时间失败", e);
            }
        }
        
        return true;
    }
}
```

```kotlin
import android.content.Context

/**
 * 完整的Android激活管理器示例

class ActivationManager(private val context: Context, private val appId: String, private val apiBaseUrl: String) {
    private val prefs: SharedPreferences = context.getSharedPreferences("activation_prefs", Context.MODE_PRIVATE)
    private val STORAGE_KEY = "app_activation_status"
    private val scope = CoroutineScope(Dispatchers.IO + SupervisorJob())
    
    /**
     * 获取MAC地址
     */
    fun getMacAddress(): String? {
        try {
            val interfaces = Collections.list(NetworkInterface.getNetworkInterfaces())
            for (networkInterface in interfaces) {
                val macBytes = networkInterface.hardwareAddress ?: continue
                val sb = StringBuilder()
                for (byte in macBytes) {
                    sb.append(String.format("%02X:", byte))
                }
                if (sb.isNotEmpty()) {
                    sb.deleteCharAt(sb.length - 1)
                    val mac = sb.toString()
                    if (!mac.equals("02:00:00:00:00:00", ignoreCase = true) && mac.isNotEmpty()) {
                        return mac
                    }
                }
            }
            return null
        } catch (e: Exception) {
            Log.e("Activation", "获取MAC地址失败", e)
            return null
        }
    }
    
    /**
     * 通过MAC地址验证
     */
    suspend fun verifyByMac(mac: String, name: String? = null, deviceId: String? = null): Result<JSONObject> {
        return withContext(Dispatchers.IO) {
            try {
                val json = JSONObject().apply {
                    put("appId", appId)
                    put("mac", mac)
                    name?.let { put("name", it) }
                    deviceId?.let { put("deviceId", it) }
                }
                
                val requestBody = json.toString().toRequestBody("application/json".toMediaType())
                val request = Request.Builder()
                    .url("$apiBaseUrl/api/licenses/verify-by-mac")
                    .post(requestBody)
                    .build()
                
                val client = OkHttpClient()
                val response = client.newCall(request).execute()
                
                if (response.isSuccessful) {
                    val responseBody = response.body?.string()
                    Result.success(JSONObject(responseBody ?: "{}"))
                } else {
                    Result.failure(IOException("请求失败: ${response.code}"))
                }
            } catch (e: Exception) {
                Result.failure(e)
            }
        }
    }
    
    /**
     * 通过激活码激活
     */
    suspend fun activateByLicense(licenseKey: String, mac: String, userInfo: Map<String, String>? = null): Result<JSONObject> {
        return withContext(Dispatchers.IO) {
            try {
                val userInfoJson = JSONObject().apply {
                    put("macAddress", mac)
                    userInfo?.forEach { (key, value) -> put(key, value) }
                }
                
                val json = JSONObject().apply {
                    put("licenseKey", licenseKey)
                    put("appId", appId)
                    put("userInfo", userInfoJson)
                }
                
                val requestBody = json.toString().toRequestBody("application/json".toMediaType())
                val request = Request.Builder()
                    .url("$apiBaseUrl/api/licenses/apply")
                    .post(requestBody)
                    .build()
                
                val client = OkHttpClient()
                val response = client.newCall(request).execute()
                
                if (response.isSuccessful) {
                    val responseBody = response.body?.string()
                    Result.success(JSONObject(responseBody ?: "{}"))
                } else {
                    Result.failure(IOException("请求失败: ${response.code}"))
                }
            } catch (e: Exception) {
                Result.failure(e)
            }
        }
    }
    
    /**
     * 保存激活状态
     */
    fun saveActivationStatus(activated: Boolean, data: Map<String, String?> = emptyMap()) {
        val mac = data["mac"] ?: getMacAddress() ?: ""
        val status = JSONObject().apply {
            put("activated", activated)
            put("mac", mac)
            put("licenseKey", data["licenseKey"] ?: JSONObject.NULL)
            put("activatedAt", data["activatedAt"] ?: SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US).format(Date()))
            put("expiresAt", data["expiresAt"] ?: JSONObject.NULL)
            put("lastVerifiedAt", SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US).format(Date()))
        }
        prefs.edit().putString(STORAGE_KEY, status.toString()).apply()
    }
    
    /**
     * 获取激活状态
     */
    fun getActivationStatus(): JSONObject? {
        val stored = prefs.getString(STORAGE_KEY, null) ?: return null
        return try {
            JSONObject(stored)
        } catch (e: Exception) {
            Log.e("Activation", "读取激活状态失败", e)
            null
        }
    }
    
    /**
     * 检查是否已激活
     */
    fun isActivated(): Boolean {
        val status = getActivationStatus() ?: return false
        if (!status.optBoolean("activated", false)) return false
        
        val expiresAtStr = status.optString("expiresAt", null)
        if (expiresAtStr != null && expiresAtStr != "null") {
            try {
                val sdf = SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US)
                val expiresAt = sdf.parse(expiresAtStr)
                if (expiresAt != null && Date() > expiresAt) return false
            } catch (e: Exception) {
                Log.e("Activation", "解析过期时间失败", e)
            }
        }
        return true
    }
    
    /**
     * 应用启动时验证
     */
    suspend fun checkOnStartup(): ActivationResult {
        // 1. 检查本地激活状态
        if (isActivated()) {
            Log.d("Activation", "应用已激活（从本地缓存）")
            return ActivationResult(activated = true, fromCache = true)
        }
        
        // 2. 获取MAC地址
        val mac = getMacAddress()
        if (mac.isNullOrEmpty()) {
            return ActivationResult(activated = false, error = "无法获取MAC地址")
        }
        
        // 3. 通过MAC地址验证
        return verifyByMac(mac).fold(
            onSuccess = { data ->
                val valid = data.optBoolean("valid", false)
                if (valid) {
                    Log.d("Activation", "MAC地址验证成功")
                    saveActivationStatus(true, mapOf(
                        "mac" to mac,
                        "licenseKey" to data.optString("licenseKey", null),
                        "activatedAt" to data.optString("activatedAt", null),
                        "expiresAt" to data.optString("expiresAt", null)
                    ))
                    ActivationResult(activated = true, fromMac = true)
                } else {
                    Log.d("Activation", "MAC地址未在激活名单中: ${data.optString("message")}")
                    ActivationResult(activated = false, needLicense = true, message = data.optString("message"))
                }
            },
            onFailure = { error ->
                Log.e("Activation", "MAC地址验证失败", error)
                ActivationResult(activated = false, error = error.message)
            }
        )
    }
    
    /**
     * 使用激活码激活
     */
    suspend fun activate(licenseKey: String, userInfo: Map<String, String>? = null): ActivationResult {
        val mac = getMacAddress()
        if (mac.isNullOrEmpty()) {
            return ActivationResult(success = false, message = "无法获取MAC地址")
        }
        
        return activateByLicense(licenseKey, mac, userInfo).fold(
            onSuccess = { data ->
                val success = data.optBoolean("success", false)
                if (success) {
                    Log.d("Activation", "激活码激活成功")
                    val licenseKeyFromResponse = data.optJSONObject("license")?.optString("licenseKey")
                    saveActivationStatus(true, mapOf(
                        "mac" to mac,
                        "licenseKey" to licenseKeyFromResponse,
                        "activatedAt" to SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSS'Z'", Locale.US).format(Date())
                    ))
                    ActivationResult(success = true)
                } else {
                    ActivationResult(success = false, message = data.optString("message"))
                }
            },
            onFailure = { error ->
                ActivationResult(success = false, message = error.message)
            }
        )
    }
}
```

## 注意事项

### 1. MAC地址获取（Android）

Android平台获取MAC地址的注意事项：

- **Android 6.0 (API 23) 及以上**：
  - 无法通过 `WifiManager.getConnectionInfo().getMacAddress()` 直接获取WiFi MAC地址
  - 需要 `ACCESS_FINE_LOCATION` 或 `ACCESS_COARSE_LOCATION` 权限
  - 即使有权限，也可能返回 `02:00:00:00:00:00`（随机化MAC地址）
  
- **推荐方法**：
  - 使用 `NetworkInterface.getNetworkInterfaces()` 遍历网络接口获取MAC地址
  - 排除回环接口和无效MAC地址（`02:00:00:00:00:00`）
  - 如果无法获取真实MAC地址，可以使用Android ID作为备选标识

- **Android 10 (API 29) 及以上**：
  - 系统默认随机化MAC地址，应用无法获取真实MAC地址
  - 建议使用Android ID或其他设备唯一标识符

### 2. 本地存储选择（Android）

Android应用推荐使用以下存储方式：

- **SharedPreferences**：
  - 适合存储简单的键值对数据
  - 轻量级，性能好
  - 适合存储激活状态等简单数据
  
- **SQLite数据库**：
  - 适合存储复杂数据结构
  - 支持查询和事务
  - 适合需要频繁查询或复杂数据关系的场景
  
- **Room数据库**（推荐）：
  - Google推荐的SQLite封装库
  - 提供类型安全、编译时检查
  - 适合大型应用

### 3. 激活状态验证

- 应用启动时优先使用本地缓存的激活状态，提高启动速度
- 建议定期（如每天或每周）后台验证激活状态，确保授权有效
- 如果网络不可用，可以依赖本地缓存状态，但应提示用户网络连接问题

### 4. 应用复位后的处理

- 应用复位后，本地存储的激活状态可能丢失
- 但MAC地址仍然存在，可以通过 `verify-by-mac` API恢复激活状态
- 因此，**激活码激活时必须传入MAC地址**，这样即使激活码丢失，也能通过MAC地址恢复

### 5. 错误处理

- 网络请求失败时，应优雅降级（使用本地缓存或提示用户）
- 提供清晰的错误提示，帮助用户理解问题
- 记录错误日志，便于问题排查

### 6. 安全性（Android）

- **应用ID存储**：不要硬编码在代码中，建议使用 `BuildConfig` 或配置文件
- **敏感信息加密**：激活码等敏感信息应加密存储，可使用Android Keystore
- **HTTPS通信**：必须使用HTTPS协议进行API通信，避免中间人攻击
- **数据加密**：对SharedPreferences中的激活状态进行加密存储
- **代码混淆**：使用ProGuard或R8进行代码混淆，保护关键逻辑
- **证书固定**：对于高安全要求，可以使用SSL证书固定（Certificate Pinning）

### 7. Android特定注意事项

- **网络请求**：必须在后台线程执行，避免阻塞UI线程
- **协程使用**：推荐使用Kotlin协程处理异步操作
- **权限请求**：Android 6.0+需要运行时请求位置权限才能获取MAC地址
- **后台限制**：注意Android的后台限制，避免在后台频繁验证
- **网络状态检查**：验证前检查网络连接状态，避免无效请求

## 常见问题

### Q1: 应用复位后激活码丢失怎么办？

**A**: 应用复位后，即使激活码丢失，只要MAC地址不变，可以通过 `verify-by-mac` API验证。这就是为什么激活码激活时必须传入MAC地址的原因。

### Q2: MAC地址可以修改吗？Android 10+无法获取真实MAC地址怎么办？

**A**: 
- Android 10 (API 29) 及以上版本，系统会随机化MAC地址，应用无法获取真实MAC地址
- 建议使用Android ID或其他设备唯一标识符作为备选方案
- 如果MAC地址变化，需要重新激活。建议在激活时记录设备标识，如果检测到变化，提示用户重新激活

### Q3: 如何实现定期验证？

**A**: 可以在应用启动时或定时任务中调用 `verify-by-mac` API，验证成功后更新本地激活状态和最后验证时间。

### Q4: 离线状态下如何使用？

**A**: 离线状态下，应用依赖本地缓存的激活状态。建议在联网时定期验证，确保授权有效性。Android应用可以使用 `WorkManager` 在后台定期验证激活状态。

### Q6: Android应用如何实现定期验证？

**A**: 可以使用以下方式：
- **WorkManager**：Google推荐的后台任务调度库，适合定期验证
- **AlarmManager**：系统级定时任务，但Android 8.0+有限制
- **应用启动时验证**：每次应用启动时验证一次
- **网络状态监听**：当网络恢复时自动验证

### Q5: 多个设备使用同一个激活码可以吗？

**A**: 这取决于授权系统的配置。通常一个激活码只能绑定一个MAC地址。如果需要多设备使用，需要多个激活码或使用MAC白名单功能。

## 总结

1. **优先使用MAC地址验证**：应用启动时首先通过MAC地址验证，如果MAC地址在激活名单中，自动激活
2. **激活码激活必须传入MAC地址**：这样即使应用复位后激活码丢失，也能通过MAC地址恢复激活状态
3. **本地存储激活状态**：将激活状态保存到本地，下次启动时直接读取，提高启动速度
4. **优雅的错误处理**：网络失败时使用本地缓存，提供清晰的错误提示

通过以上流程，您的应用可以实现可靠的授权验证功能，同时提供良好的用户体验。

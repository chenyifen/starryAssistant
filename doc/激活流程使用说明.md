# 激活流程使用说明

## 概述

已成功集成基于MAC地址和激活码的授权激活系统。系统支持两种激活方式：

1. **MAC地址白名单激活**：如果设备的MAC地址在服务器白名单中，应用启动时自动激活
2. **激活码激活**：用户输入激活码进行激活，激活时会绑定MAC地址

## 集成内容

### 1. 核心类

- **LicenseActivationManager** (`com.ai.voice.license.LicenseActivationManager`)
  - 单例模式，负责激活验证和状态管理
  - 提供MAC地址验证、激活码激活等功能

- **ActivationDialog** (`com.ai.voice.license.ActivationDialog`)
  - 激活码输入对话框
  - 处理用户输入和激活流程

### 2. 集成位置

- **App.onCreate()**: 初始化激活管理器，后台验证激活状态
- **FloatingLauncherActivity**: 在启动服务前检查激活状态，如未激活则显示对话框

### 3. 权限配置

已在 `AndroidManifest.xml` 中添加以下权限：
- `INTERNET` - 网络访问
- `ACCESS_NETWORK_STATE` - 网络状态检查
- `ACCESS_WIFI_STATE` - WiFi状态（用于获取MAC地址）
- `ACCESS_FINE_LOCATION` - 精确位置（Android 6.0+获取MAC地址需要）
- `ACCESS_COARSE_LOCATION` - 粗略位置（Android 6.0+获取MAC地址需要）

### 4. 网络安全配置

已在 `network_security_config.xml` 中配置允许激活API服务器（`47.242.60.149`）的HTTP明文流量。

## 激活流程

### 应用启动流程

```
应用启动 (FloatingLauncherActivity)
    ↓
检查权限
    ↓
权限通过后检查激活状态
    ↓
已激活？
    ├─ 是 → 启动服务
    └─ 否 → MAC地址验证
            ↓
        MAC地址在白名单？
            ├─ 是 → 保存激活状态 → 启动服务
            └─ 否 → 显示激活码输入对话框
                    ↓
                用户输入激活码
                    ↓
                激活成功 → 保存状态 → 启动服务
```

### MAC地址获取

系统会按以下顺序尝试获取MAC地址：

1. **NetworkInterface** - 遍历网络接口获取MAC地址（推荐）
2. **WifiManager** - 通过WiFi管理器获取（Android 6.0以下）
3. **Android ID** - 如果无法获取MAC地址，使用Android ID作为备选

## 使用示例

### 检查激活状态

```kotlin
val activationManager = LicenseActivationManager.getInstance()
if (activationManager.isActivated()) {
    // 已激活
} else {
    // 未激活
}
```

### 手动触发激活验证

```kotlin
lifecycleScope.launch {
    val activationManager = LicenseActivationManager.getInstance()
    val result = activationManager.checkOnStartup()
    
    if (result.activated) {
        // 激活成功
    } else if (result.needLicense) {
        // 需要激活码
        ActivationDialog.show(context, lifecycleScope) {
            // 激活成功回调
        }
    }
}
```

### 使用激活码激活

```kotlin
lifecycleScope.launch {
    val activationManager = LicenseActivationManager.getInstance()
    val result = activationManager.activate("YOUR-LICENSE-KEY")
    
    if (result.success) {
        // 激活成功
    } else {
        // 激活失败: result.message
    }
}
```

## 激活状态存储

激活状态保存在 `SharedPreferences` 中，包含以下信息：

- `activated`: 是否已激活
- `mac`: MAC地址
- `licenseKey`: 授权码（如果有）
- `activatedAt`: 激活时间
- `expiresAt`: 过期时间（如果有）
- `lastVerifiedAt`: 最后验证时间

## 注意事项

1. **MAC地址限制**：
   - Android 10+ 系统会随机化MAC地址，可能无法获取真实MAC地址
   - 如果无法获取MAC地址，系统会使用Android ID作为备选

2. **网络请求**：
   - 所有网络请求在后台线程执行，不会阻塞UI
   - 网络失败时会使用本地缓存的激活状态

3. **激活验证时机**：
   - 应用启动时自动验证
   - 如果本地已激活，直接使用缓存，提高启动速度

4. **错误处理**：
   - 网络错误时允许应用继续使用（可配置为阻止启动）
   - 激活失败会显示错误提示

## 🚀 快速开始

### 1. 应用启动

```
首次启动 → 自动跳转到激活管理界面
再次启动 → 直接进入应用（已激活）
```

### 2. 激活操作（遥控器）

```
1. 方向键 ↓ → 选中"输入激活码"
2. 确认键 → 打开虚拟键盘
3. 输入激活码：
   - 方式A：方向键选择字符 + 确认键
   - 方式B：遥控器数字键直接输入
4. 方向键 → 选中"提交激活" → 确认键
5. 等待验证...
6. 成功 → 选中"继续使用" → 确认键
```

## 🐛 问题排查

### 查看日志

```bash
adb logcat | grep -E "LicenseActivation|ActivationManagement"
```

### 常见问题

**Q: 启动时没有跳转到激活界面？**  
A: 检查本地是否已激活：查看日志中的"本地已激活"

**Q: 遥控器焦点不清晰？**  
A: 检查drawable资源是否正确加载

**Q: 激活失败？**  
A: 检查网络连接和API地址配置

**Q: 加密错误？**  
A: 系统会自动降级为明文存储，查看日志

# 系统预装版本构建说明

## 概述

项目支持两种构建版本：
1. **普通版本 (normal)**：需要申请录音和通知权限，使用普通应用UID
2. **系统预装版本 (system)**：使用系统UID，自动拥有系统级权限，不需要申请录音和通知权限

## 版本对比

| 特性 | 普通版本 (normal) | 系统预装版本 (system) |
|------|------------------|---------------------|
| **Flavor** | `normal` | `system` |
| **sharedUserId** | 无（普通应用UID） | `android.uid.system` |
| **签名** | 510en | starry |
| **RECORD_AUDIO权限** | ✅ 需要申请 | ❌ 已移除（系统自动拥有） |
| **POST_NOTIFICATIONS权限** | ✅ 需要申请 | ❌ 已移除（系统自动拥有） |
| **FOREGROUND_SERVICE_MICROPHONE** | ✅ 需要 | ❌ 已移除 |
| **权限申请流程** | ✅ 会弹出权限对话框 | ❌ 跳过权限申请 |
| **BuildConfig.IS_SYSTEM_BUILD** | `false` | `true` |
| **APK文件名** | `VoiceAssistant-版本号-Release.apk` | `VoiceAssistant-版本号-System-Release.apk` |

## 构建命令

### 普通版本（需要申请权限）

```bash
# 使用脚本（推荐）
./run_release.sh

# 或手动构建
./gradlew assembleNormalRelease
```

**输出位置**: `app/build/outputs/apk/normalRelease/`

### 系统预装版本（不需要申请权限）

```bash
# 使用脚本（推荐）

# 或手动构建
./gradlew assembleSystemRelease
```

**输出位置**: `app/build/outputs/apk/systemRelease/`

## 权限处理逻辑

### 普通版本 (normal)

1. **FloatingLauncherActivity** 启动时会检查权限
2. 如果缺少 `RECORD_AUDIO` 或 `POST_NOTIFICATIONS`，会弹出权限申请对话框
3. 用户授予权限后，应用才能正常使用

### 系统预装版本 (system)

1. **PermissionHelper.isSystemApp()** 通过 `BuildConfig.IS_SYSTEM_BUILD` 判断是否为系统版本
2. 如果是系统版本，`getMissingBasicPermissions()` 返回空数组
3. **FloatingLauncherActivity** 检测到没有缺失权限，直接跳过权限申请流程
4. 应用直接启动，无需用户交互

## 代码实现

### BuildConfig 标志

```kotlin
// normal版本
buildConfigField("boolean", "IS_SYSTEM_BUILD", "false")

// system版本
buildConfigField("boolean", "IS_SYSTEM_BUILD", "true")
```

### 权限检查逻辑

```kotlin
// PermissionHelper.kt
private fun isSystemApp(context: Context): Boolean {
    // 优先检查BuildConfig标志（编译时确定）
    return try {
        val buildConfigClass = Class.forName("${context.packageName}.BuildConfig")
        val isSystemBuildField = buildConfigClass.getField("IS_SYSTEM_BUILD")
        isSystemBuildField.getBoolean(null)
    } catch (e: Exception) {
        // 如果BuildConfig不可用，回退到运行时检查
        (context.applicationInfo.flags and ApplicationInfo.FLAG_SYSTEM) != 0
    }
}

fun getMissingBasicPermissions(context: Context): Array<String> {
    if (isSystemApp(context)) return emptyArray()  // 系统版本返回空数组
    return BASIC_PERMISSIONS.filter { permission ->
        ContextCompat.checkSelfPermission(context, permission) != PackageManager.PERMISSION_GRANTED
    }.toTypedArray()
}
```

## Manifest 配置

### 普通版本 (normal)

- 在 `AndroidManifest.xml` 中声明 `RECORD_AUDIO` 和 `POST_NOTIFICATIONS` 权限
- `sharedUserId` 为空（不设置）

### 系统预装版本 (system)

- 在 `app/src/system/AndroidManifest.xml` 中使用 `tools:node="remove"` 移除权限：
  - `RECORD_AUDIO`
  - `POST_NOTIFICATIONS`
  - `FOREGROUND_SERVICE_MICROPHONE`
- `sharedUserId` 设置为 `android.uid.system`

## 安装方式

### 普通版本

```bash
adb install -r app/build/outputs/apk/normalRelease/VoiceAssistant-*-Release.apk
```

### 系统预装版本

系统预装应用需要特殊安装方式：

```bash
# 方法1：通过系统分区安装（需要root）
adb root
adb remount
adb push app/build/outputs/apk/systemRelease/VoiceAssistant-*-System-Release.apk /system/priv-app/VoiceAssistant/
adb shell chmod 644 /system/priv-app/VoiceAssistant/VoiceAssistant-*-System-Release.apk
adb reboot

# 方法2：使用系统签名后通过系统更新包安装
# （需要制作系统更新包）
```

## 验证方法

### 检查是否为系统版本

```bash
# 检查APK的sharedUserId
aapt dump badging app/build/outputs/apk/systemRelease/*.apk | grep sharedUserId

# 应该输出：sharedUserId='android.uid.system'
```

### 检查权限声明

```bash
# 普通版本应该包含RECORD_AUDIO权限
aapt dump permissions app/build/outputs/apk/normalRelease/*.apk | grep RECORD_AUDIO

# 系统版本不应该包含RECORD_AUDIO权限
aapt dump permissions app/build/outputs/apk/systemRelease/*.apk | grep RECORD_AUDIO
# （应该没有输出）
```

## 注意事项

1. **系统版本签名**：系统预装版本必须使用系统签名（starry），否则无法安装到系统分区
2. **权限移除**：系统版本的manifest中移除了权限声明，但代码中仍然会检查权限（通过BuildConfig判断）
3. **兼容性**：系统版本和普通版本的代码逻辑相同，只是通过BuildConfig标志区分行为
4. **测试**：普通版本可以在任何设备上测试，系统版本需要root设备或系统更新包

## 构建脚本

- 签名：510en
- 特点：需要申请权限

用于构建系统预装版本（systemRelease）：
- 构建命令：`./gradlew assembleSystemRelease`
- APK位置：`app/build/outputs/apk/systemRelease/`
- 签名：starry
- 特点：不需要申请权限，使用系统UID

## 常见问题

### Q: 如何确认构建的是哪个版本？

A: 检查APK文件名：
- 普通版本：`VoiceAssistant-版本号-Release.apk`
- 系统版本：`VoiceAssistant-版本号-System-Release.apk`

### Q: 系统版本安装失败怎么办？

A: 系统版本需要使用root权限安装到系统分区，或使用系统签名后通过系统更新包安装。

### Q: 普通版本和系统版本可以同时安装吗？

A: 不可以，因为包名相同（`com.ai.voice`），会冲突。需要先卸载一个版本。

### Q: 如何切换版本？

A: 使用不同的构建命令：
- 普通版本：`./gradlew assembleNormalRelease`
- 系统版本：`./gradlew assembleSystemRelease`

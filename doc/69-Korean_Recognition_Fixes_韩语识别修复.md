# 韩语识别问题修复

## 🔍 问题描述

用户说：`하화면으로 이동해죠` (回到主屏幕)  
系统无法匹配到 `home_screen` 技能

## 📋 问题分析

### 识别结果
- 用户说：`하화면으로 이동해죠`
- 应该是：`홈 화면으로 이동해줘`

### 差异对比
```
识别结果：하화면으로 이동해죠
正确应该：홈 화면으로 이동해줘
         ↑          ↑
差异1: 하 vs 홈 (ha vs hom)
差异2: 죠 vs 줘 (jyo vs jwo)
```

### 可能原因

1. **SenseVoice识别误差**
   - `홈` (hom) 被识别为 `하` (ha)
   - 韩语发音相似，容易混淆

2. **用户发音变体**
   - `이동해줘` vs `이동해죠` 都是常用表达
   - 口语中经常互换使用

3. **句子模式不够完整**
   - 原配置只有标准表达
   - 缺少常见的误识别变体

## ✅ 解决方案

### 添加识别变体

在 `device_control.yml` 的 `home_screen` 部分添加：

```yaml
home_screen:
  # 原有模式
  - 홈 화면으로 이동해줘
  - 홈 화면으로 가줘
  - 홈화면으로이동해줘
  
  # 🆕 新增变体（应对识别错误）
  - 홈 화면으로 이동해죠      # 줘 → 죠 变体
  - 하 화면으로 이동해줘       # 홈 → 하 误识别
  - 하 화면으로 이동해죠       # 组合变体
  - 하화면으로 이동해줘        # 无空格版本
  - 하화면으로 이동해죠        # 组合变体
  
  # 🆕 简化表达
  - 홈화면                   # 最简单的表达
  - 홈화면으로                # 简化版
  - 홈화면 가기               # 简化版
```

## 🔧 技术细节

### Dicio句子匹配机制

Dicio使用模式匹配引擎：
1. 将用户输入规范化（去除标点、统一大小写）
2. 与配置文件中的模式逐一匹配
3. 找到匹配后执行对应的技能

### 韩语特殊性

1. **发音相似**
   - `홈` (hom) vs `하` (ha)
   - `줘` (jwo) vs `죠` (jyo)

2. **空格可选**
   - `홈 화면` vs `홈화면` 都正确
   - 口语中经常省略空格

3. **语尾变化**
   - `해줘` (请帮我做)
   - `해죠` (做吧/对吧)
   - 意思略有不同，但都常用

fun fuzzyMatch(input: String, pattern: String): Boolean {

    return distance <= 2  // 允许2个字符差异
}
```

### 2. 音素匹配

fun phoneticMatch(input: String, pattern: String): Boolean {
    val inputPhonemes = toPhonemes(input)
    val patternPhonemes = toPhonemes(pattern)
    return similarity(inputPhonemes, patternPhonemes) > 0.8
}
```

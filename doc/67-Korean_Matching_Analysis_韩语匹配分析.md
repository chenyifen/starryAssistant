# 现有相似度算法对韩语的适用性分析

## 现有算法概述

### 1. 词分割算法（splitWords）
- 使用 `WORD_PATTERN = Regex("\\p{L}+")` 分割单词
- `\p{L}` 匹配所有Unicode字母字符，包括韩文字母
- **对韩语：✅ 可用** - 能够正确识别韩文字符

### 2. NFKD标准化（nfkdNormalizeWord）
- 使用 `Normalizer.normalize(word, Normalizer.Form.NFKD)` 
- 然后移除组合标记 `\p{InCombiningDiacriticalMarks}`
- **对韩语：⚠️ 可能有问题** - NFKD会将韩文音节分解为字母

### 3. 评分算法（StandardScore）
- 词匹配权重：WORD_WEIGHT = 1.0f
- 字符匹配权重：CHAR_WEIGHT = 0.1f
- 使用调和平均数计算最终分数
- **对韩语：✅ 可用** - 但可能不够优化

## 潜在问题

### 问题1：NFKD标准化对韩语的影响
- 韩文音节（如"구글"）在NFKD标准化后可能被分解
- 可能导致匹配精度下降
- 例如："구글" vs "구을" 的匹配可能受到影响

### 问题2：词边界识别
- 韩语不需要空格分隔单词
- ASR识别结果可能添加空格："구글 연결해줘" vs "구글연결해줘"
- 现在通过清理文本去除空格可以部分解决

### 问题3：部分匹配权重
- 韩语中，部分字符匹配可能不如完整词匹配重要
- 例如："구을" 应该匹配 "구글"，但可能得分较低

## 建议改进方案

### 方案1：禁用韩语的NFKD标准化
- 检测到韩语时，跳过NFKD标准化
- 直接使用原始文本进行匹配

### 方案2：优化韩语匹配权重
- 增加韩语字符匹配的权重
- 降低对完整词匹配的依赖

### 方案3：添加韩语特定的相似度算法
- 使用编辑距离算法（Levenshtein Distance）
- 考虑韩语字符的相似性

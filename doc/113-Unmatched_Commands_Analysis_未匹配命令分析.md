## 关键问题总结

### 1. 匹配阈值过高 ⚠️

**问题**：High优先级技能的匹配阈值是0.7，导致很多正确识别的命令无法匹配。

**影响**：
- `모두 지워져` (0.5分) → 应该是 `clear_all`
- `형광 패` (0.5分) → 应该是 `highlighter`
- `플레이 스토 실행해 죠` (0.33分) → 应该是 `play_store`

**建议**：
- 将High优先级技能的阈值从0.7降低到0.5-0.6
- 或者添加Medium优先级技能，使用0.5-0.6的阈值

### 2. ASR识别质量差 ⚠️

**问题**：
- 多语言误识别（日语、英语、中文）
- 识别结果不完整（空字符串）
- 常见词汇识别错误（`와이파에` vs `와이파이`）

**建议**：
- 改进ASR模型的多语言识别能力
- 添加语言检测后的二次验证
- 实现文本纠错功能

### 3. 技能定义不完整 ⚠️

**问题**：某些命令在技能定义中不存在或缺少常见变体。

**缺失的命令**：
- `DisplayPort 연결해줘` → 需要添加 `display_port` 子技能
- `이메일 실행해줘` → 需要添加 `email` 子技能
- `만년필` → 需要添加 `pen` 子技能

**建议**：
- 补充缺失的技能定义
- 在句子定义中添加常见误识别变体

# 韩语技能识别失败修复总结

## 修复日期
2025-11-06

## 问题分析
通过分析 `sense_full_test_04.log`，发现多个韩语语音命令因为ASR识别错误导致技能匹配失败。主要问题是ASR将相似发音的词识别错误。

## 修复的识别错误

### 1. HDMI 相关（input_source_control.yml）

#### HDMI One 添加的变体：
- `에이치 디에마이 원 연결해줘` / `에이치 디에마이 원 연결해져`
- `에이치디에마이 일 연결해줘` / `에이치디에마이 일 연결해죠`
- `에이치디에 마이 일 연결해줘` / `에이치디에 마이 원 연결해줘`
- `에이치 디 에 마이 원` / `에이치 디 에 마이 일`
- `에이치 디 엠 아이 원` / `에이치 디 엠 아이 일`
- `마 일 연결해줘` / `마 원 연결해줘` ⭐ (ASR将"HDMI"识别成"마")
- `마 일` / `마 원`

#### HDMI Two 添加的变体：
- `에이치디의마 이 연결해줘` / `에이치디의마 이 연결해죠`
- `에이치디에마이 이 연결해줘` / `에이치디에마이 이 연결해죠`
- `에이치디에 마이 이 연결해줘` / `에이치디에 마이 투 연결해줘`
- `에이치 디 에 마이 투` / `에이치 디 에 마이 이`
- `에이치 디 엠 아이 투` / `에이치 디 엠 아이 이`
- `에이치디의 마 이 연결해줘`
- `내 마 두 연결해줘` / `내 마이 투 연결해줘` ⭐ (ASR将"HDMI"识别成"마")
- `마 이 연결해줘` / `마 두 연결해줘` / `마 투 연결해줘` / `마이 투 연결해줘`
- `마 이` / `마 두` / `마 투`

**注意**：原本错误地创建了 `mic_one` 和 `mic_two`，实际上"마"是"HDMI"的识别错误，已删除。

### 2. Front HDMI 添加的变体：
- `저면 에이치디에 마이 연결해줘` / `저면 에이치디에 마이 연결해져`
- `작년 에이치디에 마 연결해줘` / `작년 에이치디에 마 연결해죠` ⭐ (ASR将"전면"识别成"저면"/"작년")
- `전면 에이치디에 마이`
- `저면 hdmi 연결해줘` / `작년 hdmi 연결해줘`

### 3. DP Port 添加的变体：
- `기티포트 연결해줘` / `기티포트트 연결해줘` / `기티포트트 연결해져` ⭐ (ASR将"디피포트"识别成"기티포트")
- `기티포트` / `기타포트 연결해줘` / `기타 포트 연결해줘`

**注意**：原本错误地创建了 `other_port`，实际上是"DP PORT"的识别错误，已删除。

### 4. Front USB-C 添加的变体：
- `유예슬비 씨 연결해줘` / `유예슬비 씨 연결해죠` ⭐ (ASR将"유에스비 씨"识别错误)
- `유에스비 씨 연결해죠` / `유에스비씨 연결해죠`
- `유 에스 비 씨 연결해줘` / `유 에스 비 씨 연결해죠`

### 5. OPS 添加的变体：
- `오피에을 연결해줘` / `오피에을 연결해죠`
- `오피피에스 연결해줘` / `오피피에스 연결해져`
- `오피을 연결해줘` / `오피을 연결해죠`
- `오피 에스 연결해줘` / `오 피 에스 연결해줘`

### 6. Google（app_launcher.yml）
- `국을 연결해 줘` / `국을 연결해줘` ⭐ (ASR将"구글"识别成"국")

### 7. Browser（app_launcher.yml）
- `인터넷 연결해죠` ⭐ (从 input_source_control 移动到 app_launcher)
- `북을 연결해줘` / `북을 연결해죠` ⭐ (ASR将"브라우저"识别成"북")

**注意**：从 input_source_control 删除了 `internet` 句子ID，因为"인터넷 연결해줘"的意图是打开浏览器，不是切换输入源。

## 修改的文件

1. **app/src/main/sentences/ko/input_source_control.yml**
   - 为 hdmi_one、hdmi_two、dp_port、front_hdmi、front_usb_c、ops 添加识别变体
   - 删除了 `mic_one`、`mic_two`、`other_port`、`internet` 段落

2. **app/src/main/sentences/ko/app_launcher.yml**
   - 为 google 添加识别变体：`국을 연결해줘`
   - 为 browser 添加识别变体：`인터넷 연결해죠`、`북을 연결해줘`、`북을 연결해죠`

3. **app/src/main/sentences/skill_definitions.yml**
   - 从 input_source_control 删除了 `mic_one`、`mic_two`、`other_port`、`internet` 的句子ID定义

## 关键发现

1. **"마" ≈ "HDMI"**：ASR经常将"HDMI"识别为"마"
2. **"국" ≈ "구글"**：ASR将"구글"(Google)识别为"국"
3. **"북" ≈ "브라우저"**：ASR将"브라우저"(Browser)识别为"북"
4. **"기티포트" ≈ "디피포트"**：ASR将"DP PORT"识别为"기티포트"
5. **"저면"/"작년" ≈ "전면"**：ASR将"전면"(前面)识别为"저면"或"작년"
6. **"유예슬비" ≈ "유에스비"**：ASR将"USB"的韩语发音识别错误

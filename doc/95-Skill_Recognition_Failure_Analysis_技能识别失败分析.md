# 技能识别失败问题分析报告

## 日志文件
`sense_full_test_05.log`

## 问题概述

播放测试音频后，部分命令无法正确识别或执行错误的技能。主要问题包括：

1. **技能执行错误**：匹配到正确的技能类别，但执行了错误的子技能
2. **ASR识别错误**：部分命令识别不准确
3. **状态混乱**：技能执行结果与TTS回复不匹配

---

## 问题详细分析

### 1. 窗口模式命令执行错误 ❌

**问题描述**：
- **ASR识别**：`윈도우 모드로 바꿔죠` (切换到窗口模式) ✅ 正确
- **技能匹配**：`system_navigation` (评分: 0.67) ✅ 正确
- **执行结果**：`입력 소스 선택을 여는 중입니다` (打开输入源选择) ❌ **错误！**

**日志位置**：
```
11-07 00:19:15.467 - ASR结果: 윈도우 모드로 바꿔죠
11-07 00:19:15.486 - ✅ 匹配技能: system_navigation, 评分: 0.6666667
11-07 00:19:15.486 - BaseDeviceControlSkill: 打开输入源选择  ❌
11-07 00:19:15.489 - 技能执行: system_navigation, 结果: 입력 소스 선택을 여는 중입니다
```

**根本原因**：
在 `BaseDeviceControlSkill.kt` 中，`executeWindowMode()` 方法错误地调用了 `executeInputSource()`：

```kotlin
fun executeWindowMode(ctx: SkillContext): SkillOutput {
    return executeInputSource(ctx)  // ❌ 错误！
}
```

**修复方案**：
已修复 `executeWindowMode()` 方法，改为正确的窗口模式切换实现。

---

### 2. 白板命令TTS回复错误 ❌

**问题描述**：
- **ASR识别**：`화이트보드 실행해죠` (执行白板) ✅ 正确
- **技能匹配**：`whiteboard_tools` (评分: 1.0) ✅ 正确
- **执行动作**：`打开白板` ✅ 正确
- **TTS回复**：`입력 소스 선택을 여는 중입니다` ❌ **错误！应该是白板相关的回复**

**日志位置**：
```
11-07 00:19:31.537 - ASR结果: 화이트보드 실행해죠
11-07 00:19:31.594 - ✅ 匹配技能: whiteboard_tools, 评分: 1.0
11-07 00:19:31.594 - BaseDeviceControlSkill: 打开白板  ✅
11-07 00:19:31.596 - 🗣️ [DEBUG] getSpeechOutput() 返回: '입력 소스 선택을 여는 중입니다'  ❌
```

**可能原因**：
1. 状态管理混乱，之前的技能执行结果被错误保留
2. `VoiceAssistantStateProvider` 中获取 `speechOutput` 时使用了错误的状态

**需要检查**：
- `VoiceAssistantStateProvider.convertSkillOutputToSimpleResult()` 方法
- 技能执行结果的状态管理逻辑

---

### 3. WiFi连接命令识别失败 ❌

**问题描述**：
- **ASR识别**：`와이파에 연결해줘` ❌ 应该是 `와이파이 연결해줘` (WiFi连接)
- **技能匹配**：无匹配，使用fallback ❌

**日志位置**：
```
11-07 00:20:17.071 - ASR结果: 와이파에 연결해줘
11-07 00:20:17.086 - ⚠️ 无匹配技能，使用fallback
11-07 00:20:17.087 - 技能执行: text, 结果: 이해하지 못했습니다
```

**对比成功案例**：
```
11-07 00:21:49.445 - ASR结果: 와이파이 연결해줘  ✅ 正确识别
```

**根本原因**：
1. **ASR识别错误**：`와이파이` (WiFi) 被识别为 `와이파에`
2. **技能匹配失败**：由于ASR识别错误，无法匹配到 `wifi_connect` 子技能

**解决方案**：
1. 在技能匹配前添加文本纠错逻辑，处理常见的ASR识别错误
2. 在 `system_navigation.yml` 中添加 `와이파에` 的变体

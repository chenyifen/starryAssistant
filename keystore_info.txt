## 使用说明
1. 将此keystore文件保存在安全的地方
2. 密码信息请妥善保管，不要泄露
3. 用于签名release版本的APK

## 签名命令示例

### 使用 Gradle 自动签名 (推荐)
已在 app/build.gradle.kts 中配置，运行以下命令即可：
```bash
./gradlew assembleNoModelsRelease
```

### 使用 apksigner 手动签名
```bash
apksigner sign --ks release.keystore \
  --ks-key-alias ai_voice \
  --ks-pass pass:starry123 \
  --key-pass pass:starry123 \
  your_app.apk
```

### 验证签名
```bash
apksigner verify --verbose your_app.apk
```

### 查看证书信息
```bash
keytool -list -v -keystore release.keystore -storepass starry123
```
